# EduSphere 🏫

A complete, multi-tenant School Management System SaaS platform designed to host and manage multiple school databases.

## 🚀 Tech Stack
* **Frontend**: Next.js 16 (App Router, Turbopack) + TypeScript + Tailwind CSS v4 + Shadcn/ui
* **Backend**: Node.js + Express 5 + MongoDB (Mongoose)
* **Real-time Notifications**: Meta WhatsApp Cloud API Integration
* **Billing System**: SSLCommerz Sandbox + PDFKit Auto-Receipt Generation

## 📂 Repository Structure
* `/frontend` — Next.js client application
* `/server` — Express REST API application
